A full-stack web application designed to efficiently organize and manage records. This project was built from scratch to demonstrate secure backend database management and a fast, interactive frontend user experience.

## 🚀 Key Features

* **Complete CRUD Operations:** Create, Read, Update, and Delete records seamlessly using manual database connections and stored procedures.
* **Dynamic User Experience:** Implemented **jQuery AJAX** to fetch and display data instantly in the background, allowing the page to update without requiring a full browser refresh.
* **Modern Interface:** Designed a clean, responsive, and user-friendly web interface using **Bootstrap** and **Razor syntax**.

## 💻 Tech Stack

* **Backend:** C#, ASP.NET MVC, ADO.NET
* **Database:** SQL Server (using explicit Stored Procedures)
* **Frontend:** HTML/CSS, JavaScript, jQuery, AJAX, Bootstrap

## ⚙️ How to Run This Project

1. Download or clone the repository to your local machine.
2. Open `Student Management System.sln` in Visual Studio.
3. Open SQL Server Management Studio (SSMS) and run the provided SQL scripts to create the database, tables, and stored procedures.
4. Update the `SqlConnection` string in the Controller to match your local SQL Server instance.
5. Build and run the project using IIS Express.
